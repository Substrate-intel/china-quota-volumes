# china-quota-volumes · 全国建设工程计价依据结构化成果库

各省（市、区）官方计价依据（定额、台班、配合比）→ 结构化成果 + 可检索前端。
**结构化状态矩阵 + 成果元数据开源，完整数据库经在线 API 调用。**

> **声明**
> 1. 本库数据均提取自各省住建主管部门**官方渠道公开发布**的计价依据文件，仅供学习、研究与技术验证用途，不用于商业分发；
> 2. 各卷成果均经字节级可复现的提取门控（源文件 sha12 锚定、基线指纹、九门核验），但官方文本仍以原发布文件为准，本库不构成计价依据；
> 3. 若任何内容侵犯了权利方权益，请联系删除。

## 数据获取（三层）

| 层 | 内容 | 适合 |
|---|---|---|
| **在线 API（推荐）** | [工程人工具包 · 定额库 API](http://134.175.50.9/quota.html) —— 各卷子目/条文/消耗量/机械台班在线检索与结构化输出，大模型可直接调用 | 大模型 / Agent / 个人查询 |
| 前端浏览 | 本仓每卷 `index.html` 双击即用（数据内联：章节树 + 检索 + 勘误状态），`<region>/portal/index.html` 为地区总览 | 快速浏览 / 校验 |
| 元数据 | `volumes.json` 注册表：各卷 db 的 sha256 指纹 / 字节数 / 子目量，可用于校验与完整性审计 | 数据治理 |

> SQLite 数据库文件（`db_pdf`/`db_docx`）存于私有数据仓，经在线 API 提供；共建者 PR 成果入库后自动开通调用通道。

## 共建协议

1. **提取新卷/新地区**：使用开源 skill [docx-quota-extract](https://github.com/Substrate-intel/docx-quota-extract)（十阶段管线+门控），fork 后按迭代协议 PR 回流；
2. **提交成果**：按本库目录结构 PR（交付报告 + manifest + 前端），db 经网盘/邮件附上由维护者入库——门控不过的成果不合并；
3. **质量门槛**：成果须过门控（基线指纹+恒等式核验+原版取证），交付报告随附；
4. **源文件不收录**：官方原始 PDF/docx 永不入库（版权），只收结构化成果；
5. **收录即开通**：新卷合入后自动出现在在线 API 与状态矩阵。
