## 二、忠实层方法论（本卷定版）

1. **字形映射反解**：方正 FzBookMaker 子集字体无 ToUnicode，文本层乱码；以 OCR 盒对齐投票反解 `(字体归一, 字形码) → 真字符` 映射（终版 1555 键、override 15、盒对齐率 81.1%、覆盖 100%），页眉印刷页码亦靠该映射解码实测（门7）。
2. **isspace 编码汉字**：方正书版将汉字编入空白区码，按墨盒宽/字号（≥0.68em）判别，全角间隔符经视觉实证置 override。
3. **段落合并缩进拆分**：正文续行回边（x≈61.8），术语释义行右缩 24.8pt（x≈85.9）→ `INDENT_SPLIT=8.0` 断开，目录行距 27.7pt 不误并。
4. **TOC 锚定分文档**：附录 10 个法规文件以 TOC 权威标题 + 1-4 行窗口归一化匹配定位，最长前缀优先（文号行带括号天然截断前缀），匹配去边界书名号；附件按「附件N：」前缀/短行+后接条文行拆段挂接。
5. **表题 lookahead 归属**（本卷修复）：注文续行与跨页表题形貌相同，旧版按「当前注文非空即续行」直归属，致 P20 注粘入 P21「竣工结算阶段…」表题、P25 注粘入 P26「（二）特殊地区施工增加费」表题（两表丢 caption、stage 串台）；新版普通行延迟归属——下一行为表格行则转表题候选，为结构化行（标题/条目/注/术语/附录）则归注/条目续行，并以「注 content 尾部禁出现任何表题」作门6 回归防线。
6. **疑点留痕禁臆补**：新增括号不配对扫描（行级 + 表内同列 ±3 行互补配对的竖合并碎片豁免）与「数字 c 缺 m」单位残留扫描，实证均为原书 PDF 内容流漏字（P19 渲染目视确认），忠实层不补。

## 五、材料单价计取分析（用户专项）

> 结论先行：**本《费用定额》自身不列材料单价，材料单价在配套的 2020 版消耗量定额基价与地区单位估价表中计取；其计取规则由「四要素构成 + 营改增除税调整 + 两级发布 + 价差动态调整」四层构成，全部证据在本卷内闭环（第一章第一节定义 + 附录 D014 调整方法 + 总说明/通知配套口径 + 第一章第三节计算程序）。**

### 5.1 配套关系：费用定额与消耗量定额的分工

- 总说明三 / 印发通知四：本《费用定额》与 2020 版《房屋建筑与装饰工程消耗量定额》《通用安装工程消耗量定额》（TY02-31-2015）、2020 版《安装工程补充消耗量定额》、2020 版《市政工程消耗量定额》以及**自治区各地建设主管部门发布的相应地区单位估价表**配套使用。
- 总说明四：国家规定「费用定额与直接费定额一般应配套使用，执行什么直接费定额，就采用相应的费用定额」。
- 分工实质：**消耗量定额/单位估价表载「量、价、基价」（材料单价即居其中），费用定额载「费、率、程序」**（取费基数、费率、计算程序），两者以「基价→取费」衔接。

### 5.2 材料费的四要素构成（第一章第一节，P12 印2）

材料费 = 材料原价 + 运杂费 + 运输损耗费 + 采购及保管费，定义如下：

1. **材料原价**：材料、工程设备的出厂价格或商家供应价格；
2. **运杂费**：材料、工程设备自来源地运至工地仓库或指定堆放地点所发生的全部费用；
3. **运输损耗费**：材料在运输装卸过程中不可避免的损耗；
4. **采购及保管费**：组织采购、供应和保管材料、工程设备过程中所需要的各项费用，包括采购费、仓储费、工地保管费、仓储损耗。

### 5.3 营改增除税调整方法（附录 D014，新建标〔2016〕2号，P59 印47）

D014《关于建筑业营业税改增值税调整新疆建设工程计价依据的实施意见》「四、调整方法（二）材料价格」定版了材料单价的增值税处理规则：

| 要素 | 除税处理规则 |
|---|---|
| 材料原价 | 按增值税下**不含进项税额**的价格确定 |
| 运杂费 | 按不含进项税额的费用确定 |
| 采购保管费 | 按不含进项税额的费用确定 |
| 其他材料费、摊销材料费（定额以「元」为单位列项者） | **乘以系数 0.89 扣减进项税额** |
| 材料暂估单价、工程设备暂估单价（工程量清单） | 应为**除税单价** |
| 专业工程暂估价 | 应为不含进项税额的税前工程造价 |
| 风险幅度 | 均以材料（设备）等**除税单价**为依据计算 |

- **人工单价不做调整**：人工单价组成内容是工资，不含进项税额（D014「（一）人工单价」）——与材料/机械的除税处理形成对照。
- **机械台班对照口径**：台班折旧费、大修理费、经常修理费、燃料动力费等按不含进项税额确定；定额中以「元」为单位的其他机械费、零星机械费按 **0.91** 扣减（D014「（三）施工机械台班单价」）。
- **税率时点差异（重要）**：D014 成文时工程造价 = 税前工程造价 ×（1+11%）；本卷第二章第六节税金表（P29 印19）现行税率为**一般计税 9%（增值税销项税）/ 简易计税 3%（增值税征收率）**，计税基数均为税前工程造价。引证 D014 方法时税率按本卷执行。

### 5.4 除税材料预算价格两级发布机制

D014 定版：各专业定额基价中材料价格按上述方法扣除进项税额后——

1. **自治区级**：由住房和城乡建设厅工程造价管理总站发布**乌鲁木齐地区除税材料预算价格**（D014 附件2）；
2. **地州级**：各地州、市建设行政主管部门发布**本地区除税材料预算价格**。

机械台班除税预算价格同机制发布（D014 附件3）。营改增后各地州、市工程造价管理机构应及时采集、测算、发布满足计价需要的价格信息（D014「五、有关要求（一）」）。

### 5.5 价差动态调整机制（第一章第三节计算程序）

竣工结算阶段计算程序（P21 印11）设「工料机价差」科目，将价格波动纳入结算：

- 分部分项工程费 = ∑（工程数量×综合单价 + **工料机价差**）；
- 4.工料机价差 = ∑（人工费价差 + **材料费价差** + 机械费价差）；
- 单价措施项目费同步设 8.工料机价差（同构）。

招投标阶段程序（P19 印9）不设价差科目（∑工程量×综合单价），价格风险按 5.3 节「风险幅度以除税单价计」原则在综合单价中考虑；招标控制价与投标报价计税方法应当一致（P20 注4）。

### 5.6 材料费与取费基数的关系（易错点）

本卷各项取费基数均**不含材料费**：企业管理费、利润（P27 印17，T009/T010）与安全文明施工费（P23 印13，T005）计费基数均为「人工费+机械费」。材料费通过消耗量定额基价进入分部分项工程费后，不再作为费率计取基数——材料单价的变动只影响分部分项工程费总额与工料机价差，不放大取费。
