## 二、忠实层方法论

1. **表格坐标级重建**：P2 两张费率表正文文本流顺序错乱，禁用流序切表；以 pymupdf `find_tables` 坐标重建，T001 断言 3 行×6 列且费率列均为 `%` 形态、T002 断言 5 行×3 列且序号 1-4 连续。
2. **表格外正文块按 bbox 排除**：P2 正文块与表格区混排，按表格 bbox 剔除表格内 span，防表格文本重复入 items（`p2_paras` 取证留痕）。
3. **解读 docx body 顺序 walk**（禁正则匹配 XML）：python-docx `element.body.iterchildren()` 顺序遍历段落/表格，解读章节标题（一、出台背景及意义等）入 ch03 子结构，算例（内插法 x=18.90%）与解读部门、联系方式全量落库。
4. **勘误 overlay 纪律**：官方勘误不篡改忠实层；`fee_table_cell` op 在 DB 工作层应用勘误后值，erratas 表以 `wrong_text`/`correct_text` 双值留痕、按 `errata_id` 溯源；三态核对（A 错版一致→applied / B 已更正→already_correct / C 疑点→issues 禁静默修正）。
