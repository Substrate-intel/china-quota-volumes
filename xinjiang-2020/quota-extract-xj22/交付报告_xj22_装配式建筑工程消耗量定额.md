## 二、源形态与管线选型

- **第六型源形态**：官方 PDF 96 页，中文用 FZ* 方正字体（可读 27372 字符），数字/符号/西文单位字母用 FzBookMaker 子集字体无 ToUnicode 乱码（25094 字符）。这是此前 30 卷未见的新形态。
- **charmap 反解**：OCR（rapidocr 独立视觉转写）对齐反解 FzBookMaker glyph→真实字符。`build_charmap_xj22.py` 双通道对齐自动固化 57 glyph + 语义补丁，覆盖 6 个字体子集（`0DlFont` 中文标点、`3DlFont` 数字/字母、`1DlFont`/`2DlFont` 顿号/括号、`4DlFont` Φ、`5DlFont` ≤）。charmap stats：paired 3613 / resolved 57 / ambiguous 14 / fonts 6。
- **矢量网格字符级重建**：复用 xj21 矢量网格链做结构（表格列、类别分块、分层表头），charmap 反解做内容。未走 pdfplumber extract_text（西文嵌入字体基线下沉同源坑）。
- 双页码体系：物理页 1–9（封面/总说明/目录）印页 = 物 − 1；物理页 10 起正文重新起页，印页 = 物 − 9。5 章扉页印页与目录点导页码逐章对账全等（7/25/49/61/77）。
- 编码为「章-序」，5 章各自 1..N 连续：53 / 87 / 31 / 54 / 39，共 264，零缺号零重复。首跑即达恒等式，未做人工补号。

### 本卷新增的版式处理（坑 117）

1. **类别分块**：人工/材料/机械三类别字竖排**分散在各自块内部**（非块顶锚点）→ 用 `full` 全宽横线切块，块类别由块内 c0 列第一个类别字映射。
2. **分层表头**：项目名多行分层（主名称行 + 规格行 + 合并单元格跨列）→ 用竖线（`tab["v"]`）还原合并单元格，68 个残缺项目名 → 0 空。
3. **单位行识别**：preamble「计量单位：见表」时单位值在项目名区独立行；单位片段如「10m」字符 x 间隔可达 7pt → 切分阈值 4pt→8pt，26 个 missing → 0。
4. **preamble 顺序不固定**：「工作内容」与「计量单位」两关键词分别扫描，不依赖先后（修复 5-11/5-12 计量单位在上、工作内容在下的变体）。
5. **每子目一列版式**：与 xj21「每子目多列消耗」不同，xj22 每子目独立消耗列，恒等式改为「Σ每子目消耗行数 = 2688」+「每子目恰 1 条人工 = 264」。
