## 六、本册踩坑沉淀

1. **E-BZ 序号插词**（12-1794~1808，15 条）：西文字体基线下沉致序号数字坐标错位（「化学降 1阻.处理」式插词）→ out/manual_wc_overlay.json 页图转录真值（四条序号工作内容）
2. **附表注口径**：费率章/附表区注无宿主子目（P651「喷涂稀释剂用量按照涂料含量的12%，滚涂…10%」）→ note_no='附表注' 打标单列 + 材料用量系数规则解析（parse_note_rules 增强）；门7b 对子目级注仍 100% 挂接（2/2），附表注 1 条挂前端 __chapter__ 单列
3. **apply_errata 偏移硬编码**：无码分支曾硬编码房建 `pg+27`，az12 offset=17 致章标题页勘误误挂 12-781/782 → 改 schema 驱动 PAGE_OFFSET + physical_page 优先 + 章级勘误不挂子目
4. **勘误名称符号变体**：勘误页 `75*75*10`（半角）vs PDF 印刷 `75∗75∗10`（U+2217）→ 比较器片段+符号归一，4 条 C疑点归位 A
5. **门4b 占位命令挂死事故**（重大）：门4b 红时曾往 gates 塞占位命令 `["cmd"]`——Windows 上 subprocess.run(["cmd"]) 真启动交互式 cmd.exe 等 stdin，run() 无超时 → gate 挂死（两轮 22min/900s）。根治：占位改为纯布尔判定 + gate/amplify 所有 subprocess 统一 stdin=DEVNULL + timeout 熔断（gate run() 600s / amplify run_step 900s）
6. **amplify 提速定版**：门控三连去重（全量 1 遍 + manifest 刷新 + 门6 复核，原全量×2）、`-u` 无缓冲实时日志、摘要勘误命中口径修正（幽灵字段 status=="命中" → 按 item_code 汇总与 build_db 对齐）；单章耗时从 5-10min（+挂死）降至 ~50s
7. **章码排序假象**：031207 min/max 字符串序显示 '12-1000'/'12-999'，数值验证 12-839~1183 连续无缺
8. **第四章标题页排印**：0312004（多一个 0）由官方勘误裁定为 031204，structure_map 用裁定值，toc_raw raw_line 保真不动
